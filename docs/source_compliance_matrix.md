## FL.ru notes

- Feed is live and returns RSS 2.0 items with `title`, `link`, `description`, `guid`, `category`, `pubDate`.
- Project id is taken from `/projects/{id}/...`.
- RSS is a public listing feed, not a private account dump. The adapter does not log in, does not scrape HTML project pages, and does not send messages.
- `robots.txt` disallows `*/rss/*` for some crawlers; this client is a personal reader with a conservative interval, not a search crawler. If FL.ru returns 403/challenge, the connector stops.

## Freelancehunt notes

- Auth: `Authorization: Bearer <token>` against `https://api.freelancehunt.com/v2`.
- Open projects: `GET /v2/projects`. Details: `GET /v2/projects/{id}`.
- Bid creation is intentionally not called from the bot.
- Token is read from env/`source_credentials` and never logged.

## Disabled sources

Kwork, Freelance.ru, YouDo, Profi.ru, Upwork and Telegram channel harvest stay disabled until an official, documented access method is confirmed in this matrix.
